Registrasi & Login

Sistem autentikasi ini mengamankan password dengan proses hashing Argon2id dan salt unik untuk setiap pengguna. Password asli tidak disimpan, sehingga proses login dilakukan dengan mencocokkan ulang hash dari password yang dimasukkan.

🔐
Metode
Argon2id dengan konsep memory-hard hashing dan salt
🧂
Salt
16 byte acak per pengguna menggunakan crypto.getRandomValues()
💾
Memory Block
4096 blok memori internal untuk proses hashing
🔁
Iterasi
3 pass mixing untuk meningkatkan ketahanan terhadap brute force
🚫
Password
Password asli tidak disimpan, yang tersimpan hanya salt dan hash
